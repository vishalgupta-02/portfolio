# Glyph Matrix (Experimental / Abandoned)

## Status

Experimental / Abandoned component.

## Original locations

- `src/components/ui/glyph-matrix.tsx`
- `src/components/blog/checking-glyph.tsx`

## What it did

Rendered an HTML5 Canvas-based matrix stream of animated mutating glyph characters (`01·•+*/\<>`), used during UI prototype exploration and test wrapper `checking-glyph.tsx`.

## Why it was archived

It was an experimental visual effect that was never integrated into active production pages or blog posts.

## Current replacement

Standard minimalistic theme styling and typography across the portfolio and blog pages.
