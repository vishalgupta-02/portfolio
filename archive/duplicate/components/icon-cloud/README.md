# Icon Cloud (Superseded / Abandoned UI)

## Status

Superseded / Abandoned UI component.

## Original locations

- `src/components/ui/icon-cloud.tsx`

## What it did

Rendered an interactive 3D rotating spherical cloud using Canvas 2D and Fibonacci sphere point distribution to display tech stack icon graphics with drag/rotate interaction.

## Why it was archived

The tech stack presentation was replaced by a cleaner, accessible, and responsive categorized grid with tooltips and badge chips in `SkillsSection`.

## Current replacement

- `src/components/skills-section.tsx` (`SkillsSection`)
