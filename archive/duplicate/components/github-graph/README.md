# GitHub Contribution Graph (Experimental / Abandoned)

## Status

Experimental / Abandoned component.

## Original locations

- `src/components/github-graph.tsx`

## What it did

Rendered an animated SVG/Canvas style GitHub contribution heatmap grid for `@vishalgupta-02` by fetching from `https://github-contributions-api.jogruber.de/v4`.

## Why it was archived

The component was created as an experimental widget (wrapped in the temporary test wrapper `kuchtohai.tsx`) and was not integrated into the active home page layout or experience timeline.

## Current replacement

Active experience and project history are presented through the structured `ExperienceSection` (`src/components/experience-section.tsx`) and `Projects` sections (`src/components/projects.tsx`).
